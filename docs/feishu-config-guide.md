# 飞书配置指南

## 准备工作

1. 拥有飞书开发者账号
2. 已部署企业微信与飞书桥接服务到Cloudflare Workers

## 步骤一：创建飞书应用

1. 登录飞书开发者平台：[https://open.feishu.cn/app](https://open.feishu.cn/app)
2. 点击「创建企业自建应用」
3. 填写应用信息：
   - 应用名称：填写"企业微信桥接"
   - 应用描述：填写"用于飞书与企业微信消息互通的桥接服务"
   - 上传应用图标
4. 点击「创建」完成应用创建

## 步骤二：获取应用凭证

创建应用成功后，在「凭证与基础信息」页面获取以下信息，这些信息需要配置到桥接服务的环境变量中：

- **App ID**：应用ID
- **App Secret**：应用密钥（点击「查看」按钮获取）

## 步骤三：配置权限

1. 在应用详情页面，点击「权限管理」
2. 添加以下权限：
   - 消息与通知
     - `im:message:send_msg`（发送消息）
     - `im:message:receive`（接收消息）
   - 通讯录
     - `contact:user:readonly`（获取用户信息）
     - `contact:department:readonly`（获取部门信息）
3. 点击「开通权限」
4. 部分权限需要管理员审批，请联系企业管理员完成授权

## 步骤四：设置事件订阅

1. 在应用详情页面，点击「事件订阅」
2. 点击「设置」按钮
3. 填写以下信息：
   - **请求地址 URL**：`https://your-worker-name.workers.dev/feishu`
   - **请求方法**：选择「POST」
   - **验证令牌 Verification Token**：随机生成的字符串（需与桥接服务中的`FEISHU_VERIFICATION_TOKEN`环境变量一致）
   - **加密密钥 Encrypt Key**：随机生成的字符串（需与桥接服务中的`FEISHU_ENCRYPT_KEY`环境变量一致）
4. 点击「保存」
5. 系统会自动进行URL验证，请确保桥接服务已正常运行

## 步骤五：订阅事件

1. 在事件订阅页面，点击「添加事件」
2. 搜索并选择以下事件：
   - `im.message.receive_v1`（接收消息事件）
   - `im.chat.member.leave_v1`（用户离开群组事件，可选）
   - `im.chat.member.join_v1`（用户加入群组事件，可选）
3. 点击「确定」添加事件
4. 点击「保存」完成事件订阅配置

## 步骤六：配置消息接收

1. 在应用详情页面，点击「应用功能」->「机器人」
2. 点击「添加机器人」
3. 选择「自定义机器人」
4. 填写机器人名称和描述
5. 选择可使用此机器人的群组范围
6. 点击「确认」完成机器人创建
7. 在机器人详情页面，获取Webhook地址（如果需要）

## 步骤七：配置应用发布

1. 在应用详情页面，点击「版本管理与发布」
2. 点击「创建版本」
3. 填写版本信息和更新日志
4. 点击「提交审核」
5. 联系企业管理员完成应用审批
6. 审批通过后，点击「发布」按钮

## 步骤八：测试连接

1. 确保桥接服务已正确配置飞书的环境变量
2. 在飞书客户端，向应用机器人发送一条消息
3. 检查桥接服务日志，确认消息是否被正确接收

## 常见问题

1. **URL验证失败**：
   - 检查桥接服务是否正常运行
   - 确认URL格式是否正确
   - 验证Verification Token和Encrypt Key是否一致

2. **事件接收失败**：
   - 检查事件订阅配置是否正确
   - 确认应用是否已获得相应权限
   - 查看桥接服务日志排查错误

3. **消息发送失败**：
   - 检查App Secret是否正确
   - 确认应用是否有权限发送消息
   - 验证接收者ID是否存在

4. **权限问题**：
   - 确保所有必要权限已添加并获得管理员批准
   - 检查应用是否已成功发布

## 注意事项

- 飞书应用的App Secret一旦泄露，需立即在飞书开发者平台重置
- 定期更新Verification Token和Encrypt Key以保障安全性
- 确保桥接服务的响应时间在10秒内，否则飞书会判定请求失败
- 飞书的消息格式与企业微信有所不同，桥接服务需要进行适当的格式转换
