# 企业微信配置指南

## 准备工作

1. 拥有企业微信管理员账号
2. 已部署企业微信与飞书桥接服务到Cloudflare Workers

## 步骤一：创建或选择企业微信应用

1. 登录企业微信管理后台：[https://work.weixin.qq.com/wework_admin/frame](https://work.weixin.qq.com/wework_admin/frame)
2. 进入「应用管理」->「应用」->「自建」
3. 点击「创建应用」按钮
   - 应用名称：填写"飞书桥接"
   - 应用描述：填写"用于企业微信与飞书消息互通的桥接服务"
   - 上传应用图标
   - 可见范围：选择需要使用此应用的部门和成员
4. 点击「创建应用」完成应用创建

## 步骤二：获取应用凭证

创建应用成功后，在应用详情页面获取以下信息，这些信息需要配置到桥接服务的环境变量中：

- **AgentId**：应用ID
- **Secret**：应用密钥（点击「查看」按钮获取）

## 步骤三：设置可信域名

1. 在应用详情页面，找到「可信域名」设置
2. 输入您部署的Cloudflare Workers域名，格式为：`your-worker-name.workers.dev`
3. 下载校验文件，上传到您的域名根目录（如果使用自定义域名）
4. 点击「保存」完成设置

## 步骤四：配置消息回调

1. 在应用详情页面，找到「接收消息」设置
2. 点击「设置API接收」
3. 填写以下信息：
   - **URL**：`https://your-worker-name.workers.dev/wecom`
   - **Token**：随机生成的字符串（需与桥接服务中的`WECOM_TOKEN`环境变量一致）
   - **EncodingAESKey**：点击「随机生成」按钮获取（需与桥接服务中的`WECOM_ENCODING_AESKEY`环境变量一致）
   - **数据格式**：选择「JSON」
4. 点击「保存」
5. 系统会自动进行URL验证，请确保桥接服务已正常运行

## 步骤五：设置消息加密方式

1. 在消息回调设置中，选择「加密模式」
2. 确保`EncodingAESKey`与桥接服务配置一致
3. 点击「保存」

## 步骤六：配置权限

1. 在应用详情页面，点击「权限管理」
2. 确保应用拥有以下权限：
   - 发送应用消息
   - 读取消息内容
   - 获取部门列表
   - 获取成员信息
3. 点击「同意授权」

## 步骤七：测试连接

1. 确保桥接服务已正确配置企业微信的环境变量
2. 在企业微信客户端，向应用发送一条消息
3. 检查桥接服务日志，确认消息是否被正确接收

## 常见问题

1. **URL验证失败**：
   - 检查桥接服务是否正常运行
   - 确认URL格式是否正确
   - 验证Token和EncodingAESKey是否一致

2. **消息接收失败**：
   - 检查应用权限是否正确配置
   - 确认加密模式设置是否与桥接服务一致
   - 查看桥接服务日志排查错误

3. **消息发送失败**：
   - 检查Secret是否正确
   - 确认应用是否有权限发送消息
   - 验证接收者ID是否存在

## 注意事项

- 企业微信应用的Secret一旦泄露，需立即在企业微信管理后台重置
- 定期更新Token和EncodingAESKey以保障安全性
- 确保桥接服务的响应时间在10秒内，否则企业微信会判定请求失败
